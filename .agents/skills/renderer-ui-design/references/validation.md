# 真实验证方法

这是验收行为清单，不是向用户展示一串默认风险警告。按当前任务选择相关项，记录实际执行结果。

## 工程与范围

- 对照改动前的功能与 Git diff。UI 请求中涉及 renderer / loader 的文案翻译可以保留；不要混入数据格式、采样或算法变化。
- 运行项目真实的 typecheck、相关回归与 production build。正确 base 下检查实际 JS、worker、shader、WASM 与场景资源，防止 HTML fallback 冒充成功资源。
- UI 回归主要验证可观察行为，不为配色或低影响文字写实现镜像测试。

## 浏览器操作

有浏览器能力时按其提供的接口打开真实产物。优先检查用户指定尺寸；默认参考 1920×1080、1440×900、约 1050×900、约 390×844。取最终完成布局后的截图，不把 resize 后尚未执行 ResizeObserver 的第一帧当作稳定结果。

| 场景 | 验证行为 |
|---|---|
| 首次进入 | Showcase、真实加载状态、场景名、正确比例、真实累积与 HUD |
| 切换 Inspect | 场景不重载、样本不无故归零，主视口仍占主要空间 |
| 大型场景 | 搜索并选择具体节点；记录逻辑节点数与已挂载行数；滚动到末尾并用键盘选中离屏节点 |
| Properties | 查看参数、变换和引用；打开完整 Raw Data；选择非纹理后旧缩略图不残留 |
| 面板 / resize | 收起、拖宽或键盘调整；窄屏 Drawer；切换纵横输出；页面无横向溢出 |
| 渲染控制 | 暂停、继续、reset、曝光、设置修改、场景默认/手动覆盖同步、目标采样自动暂停 |
| 输入 | 相机操作、输入框不被全局快捷键劫持、Escape / Tab / 搜索与关闭焦点 |
| 导出 / 自检 | 实际文件可下载并读取；实际 GPU 回读与错误预算正常，不用假结果 |
| 失败状态 | 在可复现条件下检查加载/权限错误；无法验证的硬件或权限状态明确标注 |

暂停在固定样本数再调整面板/窗口，便于确认纯布局没有清空累积。检查 CSS 图像边界、实际 backbuffer 和 Film/Camera 比例；这些是三件不同的事。若采用动态分辨率策略，按设计记录其明确触发的重新累积。

同时检查截图的视觉问题：方形图是否遮住标题、长源路径是否挤坏面板、手机场景选择是否只剩箭头、两个弹层是否互相遮住关闭按钮。图像比例正确不等于页面可用。

读取页面 Console；工具本身的错误不能自动归因给应用。全屏在嵌入式宿主中可能受限，检查反馈，不把拒绝请求算作已通过独立浏览器全屏验收。需要发布且已授权时，等待对应 commit 的工作流完成，再实际打开线上页面，区分本机、CI、线上与用户验收证据。

截图采用真实渲染。对比不同版本时标明窗口尺寸、场景和采样分辨率；不能把采样数或分辨率提升误称为 UI 改版带来的图像算法/性能提升。验证后恢复临时 viewport override，按工具约定清理临时页面。
